Furigana

Readings above the kanji, per character or per word, so Japanese stays readable while you play.

日本語[にほんご]を勉強[べんきょう]しています

Pinyin

Phrase-aware readings with optional tone marks, so 银行 comes out as háng rather than xíng.

我要去银行[yín háng]取钱

Live captions

Speech appears as it is spoken, in the chatbox and in a transparent overlay you can read in game.

Hello → こんにちは

Kikitan Translator is free and open source, released under the licence of the original project by YusufOzmen01. This fork adds the reading aids for language learners.

Windows 10 version 2004 or newer. Requires the Microsoft Edge WebView2 runtime, which is already part of current Windows installs.
